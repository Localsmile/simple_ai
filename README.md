# Simple AI

OpenAI 호환 Chat Completions·Responses API를 위한 브라우저 기반 채팅 클라이언트. 사용자 지정 API에 직접 연결하며, CORS 오류가 발생하는 연결에는 선택형 Cloudflare 중계를 제공한다. 대화와 설정은 브라우저에 저장한다.

[웹 앱](https://localsmile.github.io/simple_ai/)

## 주요 기능

- API 제공자별 연결 프리셋과 여러 모델 등록, 입력창에서 모델 빠른 전환
- 대화별 모델, 시스템 프롬프트, 시작 메시지, 생성 설정
- 메시지 수정·삭제, 답변 재생성·후보 선택, 대화 분기·제목 변경
- 이미지·텍스트 파일 첨부, 드래그앤드롭, 클립보드 이미지 붙여넣기
- Markdown, 코드 하이라이트·복사, 표, 본문 내 이미지 및 공용 이미지 크기 설정
- 스트리밍 응답, thinking 표시, 입력·출력·캐시 토큰 사용량
- 모델별 컨텍스트 한도·최대 출력 토큰·추론 방식과 레벨 설정
- 최근 대화 턴 수와 토큰 한도에 따른 전송 컨텍스트 관리
- 여러 원격 MCP 서버 연결 및 서버별 도구 선택
- 모바일 레이아웃, 다크·라이트 테마, 전송 단축키 설정

## 시작하기

1. [웹 앱](https://localsmile.github.io/simple_ai/)의 **설정 → 연결**에서 API 제공자 추가.
2. 제공자 이름, API 엔드포인트, 필요한 경우 API 키 입력.
3. 제공자 아래에 모델을 추가하고 모델 ID·토큰 한도·이미지 입력·추론 옵션 설정.
4. 입력창의 제공자별 모델 목록에서 모델 선택 후 메시지 전송.

엔드포인트·API 키·연결 방식은 제공자에 저장되고, 같은 제공자의 모든 모델이 공유한다. 컨텍스트 한도·최대 출력 토큰·추론 설정·추가 요청 JSON은 모델별로 저장된다. 기존 단일 모델 프리셋은 제공자와 하위 모델로 이전되며, 기존 대화에 서로 다른 모델·토큰 한도가 있으면 해당 설정도 별도 모델 항목으로 보존한다.

엔드포인트는 API 기본 경로, `/chat/completions` 또는 `/responses`까지 포함한 전체 주소를 지원한다. 기본 경로에는 Chat Completions 경로를 붙이고, `/responses` 전체 주소는 Responses 요청·스트림·도구 형식으로 자동 전환한다. 이미지 입력, 추론, 도구 호출은 연결한 API와 모델이 해당 요청 형식을 지원해야 한다.

### CORS 중계

브라우저 직접 호출이 CORS 정책으로 차단되는 경우 **연결 방식 → CORS 오류 시 사용**을 선택한다. 프리셋에 등록한 API 엔드포인트·모델·API 키를 그대로 사용하며, 추가 요청 옵션과 추론 설정도 변경하지 않고 전달한다.

중계는 특정 공급자로 제한하지 않으며, 공개 HTTPS 도메인의 Chat Completions·Responses 경로와 기본 HTTPS 포트를 지원한다. API 기본 경로와 전체 API 주소, 쿼리 매개변수를 사용할 수 있다. 스트리밍·일반 JSON 응답을 지원하며, 인증이 없는 API도 키 없이 연결할 수 있다. 로컬·IP 주소·사설망 대상과 리다이렉트는 허용하지 않는다.

연결 방식은 프리셋별로 저장된다. 기본값은 직접 연결이며, 기존 NVIDIA 중계 설정은 CORS 중계로 자동 전환된다. 중계는 브라우저의 CORS 제약을 해결하는 기능으로, 서버 자체의 인증 오류·접근 차단·장애·모델 형식 불일치는 해결하지 않는다. 로컬 서버 연결에는 직접 연결을 사용한다. MCP 요청은 이 중계를 경유하지 않는다.

### 대화와 메시지

선택한 제공자·모델, 시스템 프롬프트, 시작 메시지, Temperature·전송 범위·스트리밍은 대화별로 저장된다. 기존 대화를 열면 해당 설정을 복원하며, 토큰 한도와 추론 형식은 선택한 모델의 설정을 따른다. 시작 메시지는 Markdown으로 표시되며, API에는 첫 assistant 메시지로 포함된다.

답변을 재생성하면 기존 답변과 함께 후보로 보관한다. 선택한 후보만 삭제할 수 있으며, 후속 메시지가 있는 과거 답변을 재생성하거나 후보를 변경하면 새 대화로 분기된다. 각 답변에는 생성에 사용된 모델과 프리셋 이름이 표시된다.

기본 전송 동작은 PC에서 Enter 전송·Shift+Enter 줄바꿈, 터치 기기에서 Enter 줄바꿈이다. 공용 설정에서 Ctrl/⌘+Enter 전송으로 변경할 수 있다.

### 추론

모델마다 전송 형식, 사용할 레벨, 기본 레벨, 토큰 예산을 지정한다. 지원 형식은 `reasoning_effort`, `reasoning` 객체, `thinking` + `reasoning_effort`, 사용자 정의 JSON 매핑이다.

입력창에는 해당 모델에서 활성화한 레벨만 표시된다. 입력창에서 변경한 레벨은 현재 대화에 저장되며, 새 대화나 모델 전환에는 모델 기본값이 적용된다. 전송 형식·매핑·예산은 모델 설정을 따른다.

레벨 목록은 모델에서 자동 조회하지 않는다. `max`를 포함한 각 값의 지원 여부와 의미는 API 규격에 따라 다르다. `API 기본값`은 별도 추론 옵션을 추가하지 않으며, 추가 요청 JSON의 설정을 유지한다.

### 컨텍스트와 사용량

- **전송할 최근 대화 턴:** 기본 20턴. `-1`은 전체 대화.
- **컨텍스트 토큰 한도:** 자동 정리 시 최대 출력 토큰과 여유분을 제외한 범위에 맞춰 오래된 턴을 요청에서 제외. `-1`은 앱의 토큰 한도 검사를 해제.
- **대화 기록:** 전송 범위에서 제외된 메시지도 화면과 저장 기록에는 유지.
- **토큰 사용량:** API가 제공한 값을 표시. 상단 합계는 모든 답변 후보를 포함한 대화 누적 사용량.

컨텍스트 토큰 수는 추정치이며 공급자의 실제 계산과 다를 수 있다. 앱의 한도 설정은 API 서버의 컨텍스트 한도나 요청 본문 크기 제한을 변경하지 않는다.

## 파일과 이미지

텍스트·Markdown·CSV·JSON·코드 파일은 텍스트로 읽어 메시지에 포함한다. 이미지는 `image_url` 형식으로 전송하며, 이미지 입력을 활성화한 호환 모델에서 사용한다. PDF, DOCX, 오디오, 영상 첨부는 지원하지 않는다.

변환 가능한 이미지는 WebP로 압축하고 긴 변을 최대 4,096px로 축소한다. 변환 결과가 더 작을 때만 적용하며, GIF·SVG·WebP는 원본을 유지한다.

| 항목 | 제한 |
| --- | --- |
| 메시지당 첨부 수 | 6개 |
| 원본 이미지 | 파일당 40MiB |
| 처리 후 이미지 | 파일당 10MiB |
| 텍스트 파일 | 파일당 2MiB |
| 처리 후 첨부 합계 | 메시지당 20MiB |

위 값은 앱의 첨부 제한이다. 실제 API의 허용 용량과 이미지 형식은 별도로 적용된다.

## MCP

브라우저에서 직접 접근 가능한 원격 **Streamable HTTP** 서버의 도구 조회·호출을 지원한다. 인증 방식은 인증 없음, Bearer 토큰, `x-api-key`이다.

- 기본 구성은 MCP 활성화 및 Exa의 `web_search_exa` 선택.
- GitHub 읽기 전용 연결 프리셋 제공. Bearer 인증과 [GitHub 토큰 발급 링크](https://github.com/settings/personal-access-tokens/new) 포함.
- 서버별 활성 여부와 사용할 도구를 개별 선택.
- 활성 서버에서 선택한 도구만 모델에 전달. 한 응답에서 여러 서버의 도구 호출 가능.
- 등록 서버 수와 선택 도구 수에 별도 제한 없음. API의 도구 수·컨텍스트·요청 크기 제한은 적용.

실제 도구 호출 여부는 모델이 결정하며, API의 도구 호출 지원이 필요하다. 서버 연결은 최대 3개씩 병렬 처리하고, 도구 실행은 모델이 반환한 순서대로 진행한다. 응답 생성은 최대 5라운드, 연결 요청은 20초, 도구 호출은 60초로 제한한다.

로컬 stdio 서버, OAuth 로그인, MCP resources·prompts·서버 알림 스트림은 지원하지 않는다.

## 데이터 저장과 보안

- 대화와 첨부 파일은 현재 브라우저의 IndexedDB에 저장된다. 최근 수정 순으로 최대 30개 대화를 보관하며, 초과한 오래된 대화는 삭제된다.
- 일반 설정은 `localStorage`에 저장된다. API 키와 MCP 토큰도 기본적으로 `localStorage`에 저장되며, **인증정보 로컬 저장**을 끄면 `sessionStorage`를 사용한다.
- 인증정보는 앱에서 암호화하지 않는다. 같은 출처의 스크립트와 브라우저 접근 권한이 있는 환경에서 읽을 수 있다.
- 대화와 인증정보를 GitHub 저장소에 업로드하거나 기기 간 동기화하는 기능은 없다. 브라우저 데이터 삭제 시 저장된 대화와 설정도 삭제된다.
- 메시지 전송 시 선택된 대화 내용과 첨부 파일은 연결한 API로 전송된다. MCP 호출 인자는 해당 MCP 서버로 전송되며, 도구 결과는 모델에 전달된다.
- CORS 중계 사용 시 API 키·메시지·첨부·응답은 Cloudflare를 경유한다. 중계 Worker는 이를 저장·캐시·로그 기록하지 않으며, API 키를 선택한 엔드포인트에만 전달한다. 대상 호스트의 공개 IP 확인에는 Cloudflare DNS를 사용한다. Cloudflare와 연결한 API 공급자의 서비스 처리·보존 정책은 별도로 적용된다.
- 외부 URL의 Markdown 이미지는 표시 과정에서 해당 이미지 서버에 요청한다.

직접 연결하는 API와 MCP 서버는 브라우저 호출을 위한 CORS를 허용해야 한다. HTTPS로 배포된 앱에서 일반 HTTP 원격 서버 호출은 혼합 콘텐츠 정책에 의해 차단될 수 있다. MCP 서버는 필요한 프로토콜·세션 헤더도 허용·노출해야 한다.

## 로컬 개발

Node.js 22.13 이상과 npm이 필요하다.

```sh
git clone https://github.com/Localsmile/simple_ai.git
cd simple_ai
npm ci
npm run dev
```

개발 서버 기본 주소는 `http://localhost:5173`이다. 실제 주소와 포트는 실행 시 터미널에 표시된다.

```sh
npm run typecheck
npm run lint
npm test
```

`npm test`는 프로덕션 빌드 후 테스트를 실행한다. 빌드 결과를 로컬에서 확인하려면 다음 명령을 사용한다.

```sh
npm run build
npm run preview
```

## GitHub Pages 배포

저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정한다. `main` 브랜치에 push하면 [배포 워크플로](.github/workflows/deploy-pages.yml)가 정적 결과물 `dist/`를 배포한다.

프로젝트 페이지는 저장소 이름을 기준으로 기본 경로를 자동 적용한다. 사용자·조직 페이지는 루트 경로를 사용하며, 빌드 환경의 `PAGES_BASE_PATH`로 경로를 재정의할 수 있다. 빈 값은 루트 경로를 의미한다.

## 기술 구성

React 19 · TypeScript · Vite · react-markdown · remark-gfm · rehype-highlight · IndexedDB

선택형 CORS 중계는 별도 [Cloudflare Worker](workers/nvidia-proxy/README.md)로 관리한다. GitHub Pages 배포에는 Worker 배포가 포함되지 않는다.
